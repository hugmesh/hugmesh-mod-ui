Moderator

Triage the federation moderation queue (including user self-silence appeals), recommend or escalate to an admin, ban or lift access, force a user local-only (domain-lock), block a user or instance server-wide, and review the audit trail. A moderator never removes a user directly and never decides an appeal — escalation (refer / recommend) is the path; deciding is an administrator action.

  • Moderation console Queue + status filter, recommend, ban/lift, domain-lock, server-wide block, audit.
  • System findings Automated edge-AI avatar/image findings: status filter, confirm (actioned) or dismiss (cleared).
